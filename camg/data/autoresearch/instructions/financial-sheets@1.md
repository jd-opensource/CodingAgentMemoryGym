## Public description

Title: T0 → T1 Forward Return Prediction (Financial Sheets)

Problem statement
- Predict the short‑horizon forward log return for each listed company using only T0 information from comprehensive financial statements, ratios, and market/technical features.
- Target to predict: y = log(T1_price / Current_Price), where Current_Price is the contemporaneous market price at T0 and T1_price is the matched future price.

Data description
- You are given cleaned, company‑level, cross‑sectional tabular data constructed from multiple sources (profit & loss, balance sheet, cash flow, ratios, market/technicals). All tables share a unique Id (join_key) per company.
- Final files provided for the competition:
  - train.csv: Id, all T0 features, and the target column y (forward log return).
  - test.csv: Id and all T0 features (no target).
  - sample_submission.csv: Example submission file with the correct format.
- Notes:
  - Features include accounting, ratio, ownership, liquidity, and technical indicators. Identifiers and sector information may be present and can be engineered by participants.
  - The Id is a unique company identifier and is the key required in submissions.

What you need to do
- Build a model to predict y for each Id in the test set using the T0 features from train.csv and test.csv.
- You may apply any ML techniques (feature cleaning, transformation, encoding, GBDTs, linear models, tabular deep learning, stacking/ensembling, etc.).
- Handle heterogeneous scales and missingness carefully; consider transformations (e.g., log1p, winsorization) for heavy‑tailed variables such as volume and capitalization.
- Be mindful of potential multicollinearity from overlapping sources; regularization or feature selection can help.

Evaluation
- Primary metric: Mean Absolute Error (MAE) computed on the forward log return y.
  - y_true = log(T1_price / Current_Price)
  - y_pred = your model prediction of y
  - MAE = mean(|y_true − y_pred|)
- The leaderboard displays MAE (lower is better). Values are computed only on the public test set during the competition; private scores are revealed at the end.

Submission format
- CSV with two columns and a header:
  - Id: unique identifier, exactly matching the Id values in test.csv
  - y: predicted forward log return (numeric)
- The file must contain one row per Id in test.csv, no duplicates, and no missing or non‑finite values.

Recommended modeling tips
- Start with robust baselines (e.g., Lasso/ElasticNet, LightGBM/XGBoost/CatBoost). Consider one‑hot encoding for Industry and creating market‑cap quantile features. Technical indicators may require scaling; ratios are mostly normalized.
- Avoid leakage by not using duplicated/derived targets from any secondary sources. Current_Price in train/test is the canonical present‑time price; T1_price is not provided in test.

Deliverables
- train.csv
- test.csv
- sample_submission.csv

Good luck and happy modeling!

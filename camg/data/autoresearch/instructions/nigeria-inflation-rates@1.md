## Policy actions

You have one global budget of 30 ordinary actions. Every `shell_command`, `apply_patch`, and `submit` consumes one action, including rejected or failed actions. A compound shell command is one policy action, while every managed Python start is counted separately. Use only one action per response.

- `shell_command {"command":"...","workdir":".","timeout_ms":20000}`
- `apply_patch` followed by one `*** Begin Patch` / `*** End Patch` envelope
- `submit {}` grades `submission.csv` exactly once and always terminates

`TASK.md` and `data/` are read-only. Network, package installation, GPU access, and host paths are unavailable. The shell-action wall limit is 20 seconds and the managed-runtime aggregate limit inside one shell action is 15 seconds.

## Public description

Competition: Nigeria Inflation Nowcasting (One‑Step Ahead)

Problem statement:
Given monthly macroeconomic indicators available up to month t−1, predict the headline inflation rate for month t. This is a true nowcasting task: features must reflect only information available before the target month.

Provided files:
- train.csv: Feature matrix and target for historical months. Target column: Inflation_Rate.
- test.csv: Feature matrix for the evaluation months (last 12 months). No target is included. Includes an Id column to identify rows.
- sample_submission.csv: A valid example submission file containing Id and Inflation_Rate columns.

Data description:
Each row represents one month from 2008‑01 to 2024‑06. Exogenous signals include crude oil price, production, exports, and CPI components (food, energy, health, transport, communication, education). The data contains structural breaks (e.g., CPI rebasing), strong trends in CPI indices, and occasional missing values in exogenous variables.

Feature schema provided:
- Year, Month: Calendar identifiers for the target month t.
- month_num: 1–12 indicator derived from Month.
- lag1..lag12_<feature>: t−1 to t−12 lagged values for each exogenous signal.
- lag1..lag12_missing_<feature>: 0/1 flags indicating missingness at the corresponding lag in the raw data.
- Inflation_Rate: Only present in train.csv.
- Id: Only present in test.csv and sample_submission.csv, formatted as YYYY‑MM.

Task expectations:
- Perform thorough data processing and feature engineering (e.g., seasonality, rolling statistics, MoM/YoY transformations to normalize CPI trends, careful imputation with missingness flags).
- Train robust ML models (e.g., regularized regression, tree/boosting models, ARIMAX/state‑space) that avoid leakage by using only lagged information up to t−1.
- Evaluate models properly with the provided metric and ensure reproducibility.

Evaluation metric:
- Mean Absolute Error (MAE) on Inflation_Rate over the 12 test months.
- MAE is scale‑consistent and robust under shock months/structural breaks, offering fair and precise ranking.

Submission format:
- CSV with two columns: Id and Inflation_Rate.
- Id must match the identifiers in test.csv exactly; Inflation_Rate must be numeric and finite.

Train / Test split policy:
- Train: all months up to and including 2023‑06.
- Test: the following 12 months (2023‑07 to 2024‑06).

Notes:
- Handle missing exogenous values explicitly; impute using conservative time‑series methods and include missingness indicators.
- CPI components are trending and affected by base changes; prefer rate‑of‑change features and seasonality to mitigate drift.
- Use the complete dataset; runtime is not constrained.

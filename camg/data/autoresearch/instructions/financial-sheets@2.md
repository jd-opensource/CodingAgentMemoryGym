## Public description

Financial Sheets: Industry-Neutral Forward Return Ranking (RankIC)

Problem statement
Participants must predict a cross-sectional ranking score for each company such that higher scores correspond to higher short-horizon forward log returns. Using only T0 fundamentals and market data, your model should produce a single scalar score per company in the test set.

Target definition
Forward log return y = log(T1_price / Current_Price), where Current_Price is from the T0 snapshot and T1_price is provided only to the organizers for evaluation. You should not attempt to predict T1_price per se; instead, output a ranking score monotonically aligned with y.

Files provided
- train.csv: Tabular rows (one per company) with columns:
  - Id: anonymized identifier for each company
  - Industry: industry bucket used for neutralized evaluation
  - target: forward log return label y
  - other columns: rich T0 features merged from financial statements, ratios, quarterly results, cash flows, technicals, and other metrics. Some columns may contain missing values; handle accordingly.
- test.csv: Same schema as train.csv but without the target column. Id and Industry are present.
- sample_submission.csv: Example of the expected submission format with random but valid scores.

What you need to do
- Ingest and clean heterogeneous T0 tables, engineer features, and train a model that outputs a score per Id for the test set.
- You may apply winsorization, normalization, and domain-specific transforms. Beware of duplicated or highly collinear features.
- Industry labels are provided for modeling convenience and to facilitate industry-neutral evaluation.

Submission format
- CSV with two columns without header changes:
  - Id: exactly the Id values as in test.csv
  - score: a numeric score (higher means higher forward return). Order does not matter; Ids must match exactly.

Evaluation
- We compute an industry-neutral Spearman rank correlation (RankIC):
  1) For each Industry group in test.csv, compute Spearman’s rank correlation between your score and the held-out y.
  2) Average the group correlations weighted by group size to yield the final score.
- Handling edge cases: If a group has constant scores or fewer than two samples, its contribution is 0 by definition. The final score is bounded in [-1, 1].

Notes and recommendations
- The dataset is multi-source and rich. Use all provided columns; categorical fields (e.g., Industry, exchange codes) can be encoded as needed.
- Consider robust scaling within industry or market-cap deciles to reduce cross-industry scale effects.
- Avoid label leakage: no T1 information is included in the released files; do not attempt to infer it from filenames or ordering.

Final deliverables
- A training pipeline that reads train.csv, trains your model, and outputs predictions for all Ids in test.csv.
- A submission.csv with the required format.

Data files for the competition
- train.csv
- test.csv
- sample_submission.csv

Good luck and happy modeling!

## Public description

EEG Fine-Grained Diagnostic Classification (12-class)

Problem statement
Build a machine learning model that predicts the specific psychiatric diagnosis (12 classes) from resting-state EEG-derived features. Each row corresponds to one subject with EEG band-power features per electrode and inter-electrode coherences across canonical frequency bands.

Provided files
- train.csv: Training data with features and the target column specific.disorder.
- test.csv: Test data with the same features as train.csv, without the target.
- sample_submission.csv: Example submission file showing the required format (per-class probabilities for each id).

Target and classes
- Target column: specific.disorder (multi-class, single-label)
- Classes (exact column names for submission):
  - Acute stress disorder
  - Adjustment disorder
  - Alcohol use disorder
  - Behavioral addiction disorder
  - Bipolar disorder
  - Depressive disorder
  - Healthy control
  - Obsessive compulsitve disorder
  - Panic disorder
  - Posttraumatic stress disorder
  - Schizophrenia
  - Social anxiety disorder

Features
- EEG features:
  - AB.*: Absolute band power (19 electrodes × 6 bands = 114 columns)
  - COH.*: Pairwise coherence (171 electrode pairs × 6 bands = 1026 columns)
- Demographics (optional to use): sex, age
- Excluded from train/test features: no., eeg.date, education, IQ, main.disorder, and any label columns. These are either identifiers, potential confounders, or target-related and must not be used at test time.

Submission format
- A CSV file with shape (len(test.csv), 1 + 12) and columns: id plus one column per class listed above (exact names).
- Each row contains your model’s predicted probability (or score) for each class for the corresponding id. Probabilities are recommended but not strictly required to sum to 1.

Evaluation
- Metric: Macro-averaged One-vs-Rest ROC AUC over the 12 classes.
  - For each class, the ROC AUC is computed by treating the class as positive vs all others as negative using your submitted per-class scores.
  - The final score is the unweighted mean across the 12 classes (macro average).
  - If a class happens to have only one label value in the test set (unlikely due to stratification), its AUC is defined as 0.5.
- Higher is better.

Train/test split policy (already applied in train.csv and test.csv)
- Stratified split on specific.disorder to preserve class distribution and ensure every class appears in the training set.
- Deterministic split with a fixed random seed so that all participants use the same data.
- The provided files contain all subjects; no subset is used.

Notes and recommendations
- Preprocessing: Standardize or scale features using statistics from the training data only. Consider log transforms for AB.* if skewed. Clip or winsorize extreme outliers conservatively.
- Modeling: Regularized linear models, kernel methods, gradient boosting, and neural networks can be effective. You may also engineer graph-based features from COH.* while retaining raw features.
- Validation: Use cross-validation on the training set (e.g., stratified k-fold) to select models and tune hyperparameters.
- Reproducibility: Fix random seeds and avoid leakage (do not use excluded columns).

## Public description

Agricultural Production Directional Forecast Challenge (Algeria, 1961–2023)

Files in this directory:
- features.csv: Full wide panel of yearly features (1961–2023). For target commodities only, values in test years are masked.
- train.csv: Labeled (Date, target, label) pairs for 1962–2015.
- test.csv: The (Date, target) pairs to predict for 2016–2023.
- sample_submission.csv: Example submission with placeholder labels.

Submission format
- CSV with columns: Date, target, label
- Date/target must match test.csv exactly
- label must be one of {Up, Down, Flat}

Evaluation
- Macro-averaged F1 by target across classes present in ground truth. Higher is better.
